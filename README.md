# Book Rental Kiosk

Java console application for a book rental kiosk and self-service pickup flow.

## Run

From the repository root:

```sh
javac src/Main.java
java -cp src Main
```

The `src/*.txt` files provide sample data. Personal-looking values from the local working files were replaced with synthetic examples before publishing this public repository.
